# Changelog

## 2026-07-29
- Tasks view: total tasks stat now excludes completed/cancelled tasks; added a "Due" group above "Today" for overdue tasks with a red badge.
- Tasks view: completed-list items no longer show the priority color left border; repeating tasks show a clock icon in all lists; deleting a repeating task shows a confirmation stating it will refresh again.
- Tasks view: "Completed today" counter now only counts tasks with status `done`; repeat option label changed to "Doesn't repeat"; due-date menu label now uses a short weekday (e.g. "Wed").
- Calendar: redesigned Calendar view with Daily, Weekly, and Monthly zoom levels; reusable EventCard, timeline, day/weekly selectors, and monthly grid; added category colors and mock events.
- Calendar daily view: replaced 14-day horizontal selector with a 24-hour selector using 24:00 format and event indicator dots.
- Calendar selectors: hours/days with events show up to 3 colored indicator dots; all-day events only appear on weekly and monthly selectors.
- Settings: redesigned Settings view with grouped cards, profile card, toggles, and sectioned rows matching the Dashboard visual language.
- Lists: wired the "Create new list" bottom-sheet modal from the FAB; new lists with checklist items are persisted via `listsApi`.
- Lists: extended `List`, `CreateListDTO`, and `UpdateListDTO` with optional `icon` and `color` fields so the modal choices can be persisted.
- Lists: refined "Create new list" modal — simplified checklist subtitle, added a scrollable 25-icon picker with icon preview, removed the Reminder option, and colored the Repeat icon green.
- Lists: extracted shared list-form pieces (`SelectModal`, `IconPickerModal`, `ColorPickerModal`, `OptionRow`, icon/color/repeat option lists) into `list-form-shared.tsx`.
- Lists: added an "Edit list" bottom-sheet modal (tapping a list opens it) with Accept, Cancel, and Delete (with confirmation) actions; checklist item edits are diffed and synced via `listsApi`.
- Lists: list rows now render the actual selected icon/color (with a lighter background tint) instead of a title-keyword-based theme; icon and color changes made in Create/Edit now show up immediately in the list view.
- Lists: replaced the "reset on every load" mock data with a one-time `seedDefaultLists` helper that only seeds example lists (Groceries, Workout routine, Reading list, Home repairs, Work projects, Travel bucket list) when local storage is empty, so created/edited/deleted lists now persist across reloads like the rest of the app.
- Lists: the right chevron on each list row now also opens the edit modal; the colored fill now spans the whole row (not just the icon square) — 100% for simple/collection lists, proportional to completed items for checklists.
- Lists: fixed the "Active lists" summary stat to count all non-fully-completed lists (was excluding collection-type lists); "Recent" now counts lists updated in the last 7 days instead of duplicating the total count.
- Lists: converted "Edit list" from a bottom-sheet modal into a stacked screen (slides in from the right with a back arrow), matching the Edit Task pattern.
- Lists: checklist items in both Create and Edit list now have a checkbox to mark them complete/incomplete, with completed items shown struck through; completion state is persisted via `listsApi`.
- Lists: added an explicit "Simple list" / "Checklist" toggle in Create and Edit list (list `mode` is no longer inferred from items); simple lists hide the completion checkbox on items while checklists show it.
- Calendar: removed the Daily toggle, leaving Weekly and Monthly view options; Monthly view now has left/right arrows to navigate between months.
- Calendar: added the "Add Event" bottom-sheet modal (drag handle, title/subtitle, title input with char counter, date picker, All-day toggle with a conditional time picker, Category/Repeat/Reminder menu options, and a notes textarea), opened from the FAB.
- Calendar: events are now persisted via `calendarApi` (seeded once from the existing mock events) instead of being read from static mock data; new events created from the modal are saved and immediately reflected in Weekly/Monthly views.
- Calendar: added a `calendarTagsApi` local store for event categories/tags — default tags (Personal, Health, Work, Birthday) are seeded once, and new tags created from the "Add Event" modal are persisted so they can be picked again from future events.
- Calendar: event cards now show their tag/category badge next to the chevron; tapping an event opens a stacked "Edit event" screen (matching Edit List) with the same fields as Add Event, plus Accept, Cancel, and Delete (with confirmation) actions wired to `calendarApi`. Shared Date/Time/Select/Tag picker components were extracted into `event-form-shared.tsx` and reused by both Add and Edit Event modals.
- Dashboard: summary row and cards are now wired to real data instead of mock data — "Tasks today" shows tasks due today (matching the Tasks view's "Today" group), "Events today" counts today's calendar events, "Lists" counts active (non-fully-completed) lists, and "Weekly progress" is the completion rate of tasks due this week. The Tasks/Calendar/Lists cards now render the actual today's tasks, upcoming events, and active lists from `tasksApi`, `calendarApi`, and `listsApi`; the Lists card now uses each list's real selected icon/color instead of a title-keyword guess.
- Dashboard: renamed the "Lists today" summary stat to "Active lists"; the Today's tasks card now shows "No more tasks today!" instead of "+0 more tasks" when there's nothing left to show.
- Calendar: event/day indicator dots (Weekly strip, Monthly grid, Dashboard calendar card) now use each event's actual tag color instead of only the category color; `CalendarEventTag` gained a `dotColor` field (solid color) alongside its pastel badge `color`, populated for both default and user-created tags.
- Tasks: creating, editing, or deleting a task with a due date now keeps a mirrored calendar event in sync (`tasksApi` upserts/removes a `source: "task"` event via `calendarApi`), so tasks with due dates now appear on the Calendar view at the correct date and time.
- Dashboard: summary row and cards are now wired to real data instead of mock data — "Tasks today" shows tasks due today (matching the Tasks view's "Today" group), "Events today" counts today's calendar events, "Lists" counts active (non-fully-completed) lists, and "Weekly progress" is the completion rate of tasks due this week. The Tasks/Calendar/Lists cards now render the actual today's tasks, upcoming events, and active lists from `tasksApi`, `calendarApi`, and `listsApi`; the Lists card now uses each list's real selected icon/color instead of a title-keyword guess.
